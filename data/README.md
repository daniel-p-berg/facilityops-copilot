# Sample Data

These CSV files seed the local FacilityOps Copilot SQLite database. They are fictional Northstar Data Hall records for portfolio demonstration only.

- `sample_equipment.csv`, `sample_points.csv`, `sample_current_point_values.csv`, and `sample_alarm_rules.csv` define the BMS/EPMS catalog and runtime baseline.
- `replay_samples.csv` drives deterministic point replay for generated alarm evaluation.
- `sample_facility_scenarios.csv`, `sample_alarm_correlations.csv`, `sample_alarm_correlation_members.csv`, `sample_incident_timeline.csv`, `sample_shift_turnover.csv`, `sample_equipment_out_of_service.csv`, `sample_corrective_actions.csv`, `sample_procedure_references.csv`, and `sample_reliability_reports.csv` provide the seeded operations overview shown on the dashboard.

The operations overview data is curated and explainable. It is not a live root-cause engine and is not generated from AI at runtime.
